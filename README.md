## Project Overview

This repository contains Python implementations of numerical and scientific computing techniques covered in the Scientific Computing unit.

The project demonstrates how Python libraries such as NumPy, SciPy, and Matplotlib can be used to solve mathematical and computational problems.

It covers numerical methods, matrix operations, equation solving, interpolation, optimization, numerical integration, and simulation.

## Objectives

The objectives of this project are to:

- Apply scientific computing concepts using Python.
- Perform numerical and matrix computations.
- Implement numerical methods for solving mathematical problems.
- Explore the use of scientific Python libraries.
- Interpret computational results and their practical applications.

## Technologies and Libraries

- Python
- NumPy
- SciPy
- Matplotlib

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd Scientific-Computing
   ```

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

## Running the Programs

Navigate to the `code` directory and run an individual task using Python.

For example:

```bash
python code/Task_02_numpy_arrays.py
```

Replace the filename with the task you want to execute.

## Topics Covered

The project covers:

- NumPy arrays and numerical computation
- Mathematical functions and vectorization
- Floating-point arithmetic and numerical errors
- Matrix algebra and operations
- Linear systems
- Gaussian elimination and LU decomposition
- Iterative methods for linear systems
- Eigenvalues and eigenvectors
- Bisection and fixed-point methods
- Newton-Raphson and secant methods
- Polynomial and nonlinear equations
- Interpolation
- Curve fitting and approximation
- Numerical differentiation
- Numerical integration
- Ordinary differential equations using Euler's method
- ODEs using SciPy
- Numerical optimization
- Random numbers and Monte Carlo simulation
